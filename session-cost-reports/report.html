Where the cost went

Every request sends the whole conversation so far. The first view divides the input cost of each request among the content it carried, at the rate that request paid for each part: cache reads, cache writes, or uncached input. Token counts for individual blocks are estimated from their length and scaled to match the recorded totals. The second view assigns the whole cost of each request, output included, to the tool calls it made, divided equally among them; a request that follows a failed tool call is assigned to that failure instead. For each action, the last columns count the requests that made no other tool call, and give their full cost.
